# Proyecto Urban Grocers - API Testing Projects
▫️ Descripción: 
Este proyecto se enfocó en pruebas de API para una aplicación de compras en línea.  
El objetivo fue validar que la aplicación cumpliera con los requerimientos al momento de ingresar un nuevo kit.  
Se diseñaron y ejecutaron **9 pruebas** para asegurar que no se permitiera registrar kits que incumplieran con las especificaciones.
◾️ Condiciones previas:
- Descargar el código
- Abrir Pycharm
- Necesitas tener instalados los paquetes pytest y requests para ejecutar las pruebas.
- Ejecuta todas las pruebas con el comando pytest.
- Lenguaje de programación Python
⚙️ Herramientas:
- Postman
- JSON/ Collections
- Jira
- Agile/Scrum
✅ Responsabilidades:
- Diseñar y ejecutar pruebas de API en Postman
- Validar respuestas de endpoints y flujos pedidos
- Documentar resutlados y defectos en Jira
🎯 Logros:
- Detecté insocnsistencias en la respuesta de la API en endpoints críticos.
- Aseguré la integridad de los datos en operaciones de compra.
- Contribuí a la mejora de la docuemtnación técnica de la API
